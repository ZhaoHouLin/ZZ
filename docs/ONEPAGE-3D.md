# 一頁式 + 3D 改版決策記錄

2026-09-12 — 在 `nuxt4` 分支修完捲動卡頓（commit `05cd899`）後，決定把三頁（About / Portfolio / Favorite）合併成一頁式，並在 hero 加入 WebGL 3D 物件。本文記錄提案的問答與最終決策，實作以此為準。

**提案**：(1) 為個人網站加入 3D 立體感 (2) 內容不多，改成一頁式。

**內容量**（實作前查過）：GitHub 6 個、100 Days CSS 100 個、相簿 6 張、履歷 4 條、興趣 4 項。一頁式的可行性主要卡在 100 個作品磚怎麼放。

---

## 第一輪

**Q1 — 「3D 立體感」是哪一種 3D？**
選項：A CSS 深度（視差、卡片傾斜、擠出陰影，零依賴）/ B 單一 WebGL 物件（hero 放 Three.js 物件，其餘維持 CSS）/ C 完整 3D 場景（整頁在 WebGL 裡捲動）
建議：A，剛修完卡頓，B 會把持續性的 GPU 成本加回來。
✅ **B**。代價已知，改用 Q7 的護欄把風險關住。

**Q2 — 一頁式的區塊順序**
1. Hero（ZZ 方框、圓環、時鐘、聯絡）
2. About（跑馬燈 + 逐字點亮）
3. Resume（工作 / 學習）
4. GitHub（6 張卡）
5. 100 Days CSS
6. Mountain（山脊線 + 對聯，原 Favorite 的滿版開場）
7. Interests + Album，然後 Footer

✅ **照此順序**，第 6 塊保留滿版 100vh。內容少的一頁式最怕一路平鋪到底，中段一個滿版山景是節奏上的停頓。

**Q3 — 100 個作品磚怎麼放**
選項：A 全部保留成網格，格子縮小 / B 釘住橫向捲動（ScrollTrigger pin，垂直捲動轉水平）/ C 只展示精選 12～20 個，其餘折疊
建議：A。
使用者追問「剛修完卡頓為何不推薦 B」，回答如下：B 的效能風險是「中等」而非「一定會頓」，具體成本有三：
1. 釘住需要在捲到該區時把區塊切成 fixed 並塞等高佔位元素，每次視窗大小變動（含手機網址列縮放）都要重算，容易跳動。
2. 100 格排成一列約 10000px 寬，每一幀都要位移這個超寬圖層，會和 hero 的 WebGL、視差同時跑。
3. 真正的問題是體驗：要嘛每格很小，要嘛使用者要垂直捲 8000px 以上才看得完。

✅ **B**，接受取捨，但限制條件：只釘 3～4 個視窗高的捲動距離，格子排成兩到三列。
（2026-09-12 實作後推翻：釘住捲動實際用起來不順手，改為 **D. 橫向拖曳**：原生橫向捲動容器 + GSAP Draggable `scrollLeft` 模式加慣性，3 列格子，不釘住區塊。觸控與觸控板走原生捲動，滑鼠拖曳。）

**Q4 — 導覽怎麼改**
選項：A 保留全螢幕漢堡選單，改錨點 + 平滑捲動 / B 換成常駐側邊小索引，漢堡拿掉 / C 兩者都要，漢堡放次要連結，側邊索引負責區塊跳轉
建議：A。
✅ **C**。

**Q5 — 舊網址要不要留**
選項：A 保留 `/portfolio`、`/favorite` 兩條路由轉址到錨點 / B 直接拿掉，舊連結 404
✅ **A**。成本是兩個各三行的頁面檔，換來舊連結不壞。

**Q6 — 手機上的 3D**
選項：A 手機退化成靜態（只保留捲動驅動的 Z 軸推近拉遠）/ B 用陀螺儀（DeviceOrientation）代替滑鼠
建議：A，陀螺儀的 iOS 授權彈窗和站的氣質不合。
✅ **B**，但使用者保留「先看設計再改」的空間，因此陀螺儀做成獨立開關，拿掉時不影響其他部分。

## 第二輪

**Q7 — WebGL 的護欄**
Three.js 進來後的限制：
1. 整頁只允許一個渲染迴圈，粒子星座線併進 WebGL 場景或直接拿掉，不再另開 canvas 2D。
2. hero 離開視窗就停止渲染。
3. 渲染解析度上限 DPR 1.5。
4. Three.js 用動態載入，不擋首屏；偵測到沒有 WebGL 或 `prefers-reduced-motion` 時退回現在的平面圓環。
5. 手機上多邊形與粒子數量減半。

✅ **全部接受**。少任何一條，上一輪修掉的卡頓都可能回來。

**Q8 — 3D 物件是什麼**
選項：A 體素 ZZ（像素字型點陣排成小方塊，InstancedMesh 幾百個方塊）/ B 線框多面體加粒子 / C 3D 版的圓環文字
✅ **A**。和 Pixel 字型、方框 logo 是同一套語言，B 任何模板站都有。

**Q9 — 3D 物件放哪、和圓環怎麼相處**
選項：A 取代圓環的位置，圓環文字繼續繞在外圍，計數器移到 hero 右下角資訊區 / B 放背景層取代星座線，圓環與計數器不動 / C 取代左上角的 ZZ 方框
✅ **A**。花了 Three.js 的成本，物件就該是主角。

**Q10 — 渲染風格**
選項：A 像素化渲染（四分之一解析度渲染，最近鄰放大，復古鋸齒 3D）/ B 純線框，黑底白線加琥珀邊 / C 實心平面著色，琥珀色打光
✅ **A**。既是風格選擇也是效能選擇：和 Pixel 字型一致，GPU 成本降到十六分之一。

**Q11 — 物件怎麼動**
- 閒置時緩慢自轉
- 滑鼠移動時整體跟著傾斜（手機依 Q6 用陀螺儀，另加手指拖曳可轉動）
- 往下捲時物件往 Z 軸退後並淡出，接手現在圓環 scale 1.6 淡出的角色
- 進場時方塊逐顆從散開狀態聚合成 ZZ

✅ **四個都要**。進場聚合是最有記憶點的一段，成本只在頭 1.5 秒。

**Q12 — hero 以外要不要有 3D 感**
選項：A 輕量延伸（GitHub 卡片與作品磚 hover 依滑鼠傾斜；各區標題進場從 Z 軸推近；山景區山脊線加捲動深度視差，全是 CSS transform）/ B 只有 hero
✅ **A**。零持續成本，只在互動時觸發；只有 hero 有 3D 會像兩個網站。

**Q13 — 側邊索引的內容與位置**
選項：A 六個區塊（01 About / 02 Resume / 03 GitHub / 04 CSS / 05 Mountain / 06 Album），貼右側垂直排列，Digital 字型，目前區塊亮琥珀色，手機縮成右側細進度線 / B 三個大區對應原本三頁
✅ **A**。索引的價值就在細分。

**Q14 — 漢堡選單只剩次要連結後怎麼不顯得空**
選項：A 三個大字換成 GitHub / CodePen / Mail，版面與 clip-path 開合不變 / B 大字仍放六個區塊錨點，底部小字放外部連結（與側邊索引重複）
✅ **A**。Q4 選 C 的意思就是分工。

**Q15 — iOS 陀螺儀授權怎麼觸發**
選項：A hero 底部放一個「motion」小圖示，只在 iOS 顯示，點了才授權 / B 第一次觸碰 hero 就跳授權 / C iOS 不做陀螺儀，只保留手指拖曳
✅ **A**。

## 直接採用、未另問的假設

- 捲動時不改網址的 hash，只在點索引時改，避免歷史紀錄被塞滿。
- 舊 `/portfolio`、`/favorite` 路由轉址到對應錨點（Q5）。
- hero 進場仍用 `visibility hidden` + `onMounted` 後顯示那套防閃爍。
- `page:finish` 關選單的邏輯因為不再換頁而拿掉。
- Mountain 區的對聯進場改為捲動觸發（原本是頁面掛載時播）。

## 實作順序（建議）

1. 一頁式骨架：合併三頁、側邊索引、漢堡改次要連結、舊路由轉址。此時不碰 3D，先確認捲動順暢。
2. 100 格釘住橫向捲動，量測捲動距離與手機表現。
3. WebGL 體素 ZZ：動態載入、像素化渲染、護欄全數到位，先做自轉與滑鼠傾斜。
4. 進場聚合、捲動退後淡出、粒子併入場景。
5. CSS 輕量 3D 延伸（Q12）。
6. 陀螺儀開關與 iOS 授權圖示（Q6 / Q15），最後做，方便拿掉。

## 第三輪：3D 第一版後的方向修正（2026-09-12）

3D 第一版（commit `8a28ec7`）做出來後使用者回饋：顏色不好看、`#100` 移到右上沒有意義、**原本的數字 3030 是以前工作的分機號碼**而不是 100 Days CSS、左上 ZZ 方框和 3D 的 ZZ 重複、整個設計要再想。追問後得到的背景：

- 網站給面試官、同行、也是自己的名片。
- ZZ 是綽號縮寫；對聯「走路要找難路走，挑擔要揀重擔挑」是 2019 年爬山的體會；現在的體會是考完 CKA 後的「我命由我不由天」。
- 現況：藍新資訊，2026-04 轉入智能應用發展部，尚無代表專案；持有 CKA。網站原本的自介與履歷停在前端工程師，對求職是落差。
- 參考網站：https://trionn.com/

**決策**
- 3D 物件改為**體素閃電**：閃電的鋸齒正面讀起來是上下疊的 ZZ，它就是 logo，左上 ZZ 方框拿掉。方塊與光都用白色。
- hero 主標語「我命由我不由天」，副標 AI Application · Cloud Native · Web；對聯留在山景區，標「2019 · 爬山時的體會」。
- 3030 放進左上的 LED 面板（時鐘、EXT 3030、城市），在聯絡資訊的語境裡才有意義。
- 借 trionn 的「hold to blast」：按住閃電炸開、放開聚合，重用進場的聚合動畫。不借它的整頁平滑捲動。
- 自介改寫成現在的定位，跑馬燈標籤換成 AI APPLICATION / KUBERNETES / CKA / DEVOPS / LLM / RAG / VUE 3 / NUXT / GSAP；履歷把藍新拆成兩段，學習經歷加 CKA（取得年份待補）。GitHub 六個作品與 100 Days CSS 保留為早期作品。

**教訓**：動識別元素之前先問來歷。從像素字、黑白這些表面特徵推設計，會做出好看但沒有意義、甚至重複的東西。
