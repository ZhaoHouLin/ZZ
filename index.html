內部專案

  1. 企業內部 Nuxt 3 系統

    AD / LDAP 登入、JWT Cookie session、檔案上傳下載落到 NAS（SMB CSI），部署於自建 Kubernetes，Ingress HTTPS。

  2. 自建 Kubernetes 平台

    kubeadm 從零建叢集：Calico 網路、Ingress-NGINX、Harbor registry、GitLab Runner 串成 build → push → deploy 的流程。

  3. NAS 儲存整合進 Kubernetes

    用 SMB CSI 把 NAS 掛進 Pod，PV / PVC 統一管理；解掉 Pod 內看得到檔案、外面看不到的權限與掛載問題。

踩過的坑

  • LDAP 登入失敗與 DNS timeout：Pod 內 DNS 解析與 AD 連線逐層排查
  • SMB CSI mount：Pod 裡看得到檔案、外面看不到
  • containerd 連 HTTP registry 被當成 HTTPS client 拒絕
  • Ingress TLS 與 registry 憑證鏈
